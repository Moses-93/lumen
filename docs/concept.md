# Lumen

## Problem

Human memory is not an objective record. It reconstructs the past under the influence of the present state, suppresses discomfort and smooths contradictions. As a result, causal relationships between events, feelings and life changes remain hidden — not because they do not exist, but because we lack the tools to retain them.

## Idea

Lumen is a system for chronological self-state journaling. The user captures short entries: feelings, experiences, changes. The system stores these entries, finds semantic connections between them and provides a tool for independent retrospective analysis.

A core position: the system does not interpret or draw conclusions on behalf of the user. It returns an ordered picture of one's own experience — the person interprets it themselves.

## Principles

**Privacy as a foundation.** Data stays local. Trust in a tool is impossible without confidence that the personal remains personal.

**Minimal entry threshold.** An entry has no structure, form or required fields. Any text at any moment.

**Living response.** Every entry receives an immediate reply — not a save confirmation, but a quote that semantically resonates with the moment. This creates a sense of dialogue without imposing interpretation.

**Tool, not conclusion.** Pattern analysis, temporal dynamics, semantically similar states — all of this is presented as material for reflection, not as a ready-made answer.

## Daily Interaction

**Daily Evaluation of the Day (Retention Hook):**
As a conceptual direction for user retention, the system may introduce a daily subjective evaluation of the *entire day* (e.g., on a scale of 1 to 10: "How do you feel today?").
This evaluation acts as a psychological bridge: it motivates the user to reflect on their day, and upon engaging, the app invites them to leave a detailed textual entry (a thought or event) to capture that state.

## Mechanics

Each entry is vectorized and stored with a timestamp. In parallel, a quote library exists — also vectorized. With each new entry, the system finds a semantically close quote and returns it to the user.

Over time, the accumulated entry base becomes the foundation for analysis: finding recurring states, identifying clusters, chronological cross-sections. The user receives not a diagnosis, but navigation through their own experience.

## Value

Lumen makes visible what has always existed but was never recorded. It does not change a person — it gives them the ability to see themselves through time.
